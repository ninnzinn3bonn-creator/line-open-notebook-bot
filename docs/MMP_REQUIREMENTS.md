# MMP要件確定シート

本書でMMPはMinimum Marketable Productを指す。PoC提出前に各項目の決定値、根拠、承認者を記入し、未決のまま提供開始しない。

| 区分 | 確定する内容 | 初期案 | 状態 |
|---|---|---|---|
| 利用範囲 | 対象店舗、利用者、受付チャネル | LINEの1対1テキスト | 要承認 |
| 回答範囲 | 対応カテゴリと対象外カテゴリ | 承認済み店舗FAQのみ | 要承認 |
| 禁止処理 | AIが確定してはならない事項 | 予約確定、個別見積り、返金、例外判断 | 要承認 |
| 会話 | 文脈保持とリセット | 最大3ラリー、時間TTLなし | PoC検証中 |
| 有人対応 | 経路、受付時間、応答責任者 | 電話または有人チャット | 要入力 |
| 品質 | 正答、安全回答、Critical、Source整合 | Golden Datasetと人間採点で確定 | 未確定 |
| 性能 | p50、p95、Timeout、同時数 | LINE E2E実測で確定 | 未確定 |
| 可用性 | 稼働時間、許容停止、復旧目標 | 納品後1か月のOCI観測で確定 | 未確定 |
| 費用 | API、OCI、Cloudflare、移行後VPSの月額上限 | 業務責任者が上限承認 | 要入力 |
| データ | ログ、会話、個人情報、削除期限 | 必要最小限 | 要承認 |
| 管理 | Knowledge更新者、承認者、権限 | 二者確認を推奨 | 要入力 |
| 監視 | Health、Tunnel、容量、外形監視、通知先 | 24時間の外形監視 | 要入力 |
| 保全 | バックアップ頻度、保管先、復元試験 | VM外暗号化バックアップ | 要承認 |
| 基盤 | 開発・初月とその後 | OCI＋Cloudflare、初月後にVPS移行判定 | 方針確定 |
| 受入れ | 実端末E2E、回帰、障害復旧 | 第48章と第68章に準拠 | 未実施 |

## PoC証拠に基づく暫定合否値

| 指標 | PoC合格値 | 現在の証拠 | MMP確定に必要なもの |
|---|---:|---|---|
| Critical誤回答 | 0件 | 合成40問で最終40/40 | 実店舗Golden Dataset |
| 通常回答率 | 95%以上 | 合成回帰で確認 | 実店舗質問で再測定 |
| 回答時間 | p95 15秒以内 | 合成20問p95 11.42秒、実端末3台全件成功・最遅約10秒 | 固定Tunnel＋OCIで再測定 |
| 同時利用 | 3ユーザー | 自動10件Burst、実端末3台 | 店舗のピーク想定承認 |
| 有人移管 | 対象ユーザーのみ停止 | Unit・稼働Bridgeで停止／復帰確認 | LINE公式チャットONでE2E |
| 重複返信 | 0件 | webhookEventId重複排除PASS | 固定Tunnelで再送試験 |
| 障害時 | 緊急回答1回 | Timeout・有限再試行PASS | OCI障害訓練 |
| 復旧 | 再構築・復元可能 | スクリプトと納品ZIP完成 | 空OCI VMで復元 |

上記はPoCの暫定値であり、店舗側承認欄を代替しない。

## PoCからMMPへの差分

| 分類 | 内容 |
|---|---|
| 実証済み | Open Notebook RAG、Groq 120B、3ラリー、Grounding Gate、有人ルーティング、3台同時応答 |
| 実装済み・実機待ち | OCI Compose、Named Tunnel構成、Access分離、バックアップ／復元、systemd、受入れスクリプト |
| 店舗入力待ち | 承認済みFAQ、連絡先、有人受付時間、通知担当、月額上限、データ保持期間 |
| 外部設定待ち | OCI A1、専用Cloudflare Named Tunnel、固定DNS、Access policy、LINE公式チャットON |
| 運用で補完 | Knowledge二者承認、有人対応完了操作、月次回帰、バックアップ保管 |

## PoC提出時に添付する差分表

- PoCで実証済み
- MMP提供開始までに追加実装
- 運用手順で補完
- 店舗側の入力・承認待ち
- 既知制約と許容判断
- OCI継続またはVPS移行の判定条件

最終承認は店舗側業務責任者が行い、承認日と対象Revisionを記録する。

# MMP要件確定シート

本書でMMPはMinimum Marketable Productを指す。PoC提出前に各項目の決定値、根拠、承認者を記入し、未決のまま提供開始しない。

| 区分 | 確定する内容 | 初期案 | 状態 |
|---|---|---|---|
| 利用範囲 | 対象店舗、利用者、受付チャネル | LINEの1対1テキスト | 要承認 |
| 回答範囲 | 対応カテゴリと対象外カテゴリ | 承認済み店舗FAQのみ | 要承認 |
| 禁止処理 | AIが確定してはならない事項 | 予約確定、個別見積り、返金、例外判断 | 要承認 |
| 会話 | 文脈保持とリセット | 最大3ラリー、時間TTLなし | PoC検証中 |
| 有人対応 | 経路、受付時間、応答責任者 | 電話または有人チャット | 要入力 |
| 品質 | 正答、安全回答、Critical、Source整合 | Golden Datasetと人間採点で確定 | 未確定 |
| 性能 | p50、p95、Timeout、同時数 | LINE E2E実測で確定 | 未確定 |
| 可用性 | 稼働時間、許容停止、復旧目標 | 納品後1か月のOCI観測で確定 | 未確定 |
| 費用 | API、OCI、Cloudflare、移行後VPSの月額上限 | 業務責任者が上限承認 | 要入力 |
| データ | ログ、会話、個人情報、削除期限 | 必要最小限 | 要承認 |
| 管理 | Knowledge更新者、承認者、権限 | 二者確認を推奨 | 要入力 |
| 監視 | Health、Tunnel、容量、外形監視、通知先 | 24時間の外形監視 | 要入力 |
| 保全 | バックアップ頻度、保管先、復元試験 | VM外暗号化バックアップ | 要承認 |
| 基盤 | 開発・初月とその後 | OCI＋Cloudflare、初月後にVPS移行判定 | 方針確定 |
| 受入れ | 実端末E2E、回帰、障害復旧 | 第48章と第68章に準拠 | 未実施 |

## PoC提出時に添付する差分表

- PoCで実証済み
- MMP提供開始までに追加実装
- 運用手順で補完
- 店舗側の入力・承認待ち
- 既知制約と許容判断
- OCI継続またはVPS移行の判定条件

最終承認は店舗側業務責任者が行い、承認日と対象Revisionを記録する。
